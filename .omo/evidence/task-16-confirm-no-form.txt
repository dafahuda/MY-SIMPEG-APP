# Task 16 - Confirm Handler No-Form Evidence

Scope: harden global confirm JS in `resources/views/layouts/app.blade.php` so missing form/href cases do not throw runtime errors and form submissions preserve validation/submit handlers when possible.

Files changed:
- `resources/views/layouts/app.blade.php`
- `tests/Feature/AdminSuperadminUiux/FrontendMarkupA11yBaselineTest.php`

JS changes:
- `.confirm-edit`:
  - keeps existing confirmation flow and Indonesian text.
  - adds `if (! href) return;` before opening the confirm modal.
- `.confirm-delete`:
  - adds `if (! form) return;` so a confirm-delete button outside a form does not dereference null.
  - uses `form.requestSubmit()` when available.
  - retains `form.submit()` fallback for older browsers.
- `.confirm-save`:
  - adds `if (! form) return;`.
  - uses `form.requestSubmit()` when available.
  - retains `form.submit()` fallback.

Why this satisfies Task 16:
- Missing form for confirm buttons is handled gracefully by returning early.
- `requestSubmit()` preserves browser validation and submit handlers better than direct `form.submit()`.
- Existing event delegation and modal architecture remain unchanged.

  - asserts href/form null checks exist,
